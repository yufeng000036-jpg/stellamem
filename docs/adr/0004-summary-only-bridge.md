# ADR 0004: 桥接只传摘要，不搬原文

Status: accepted, 2026-11-03.

## 原则

过桥的永远是**提炼后的摘要文本**；原始日志、原始行为数据**永不过桥**。

- 可以过桥：人工写出的摘要（如常客桥接卡"钟丽潭（2775613370801694）：2026-11-03 送小心心 x235"）、
  三个结构化模板渲染出的句子（relationship / method / result）。
- 永不过桥：原始弹幕行、原始礼物事件行、聊天 JSONL 原文、整段日志拷贝、
  批量 userId 明细、任何"把原文直接贴过来"的字段。

## 为什么

1. **可读即可审计**：摘要是人话，审批人能看懂、能核对、能改；原始数据
   搬过去等于把审计责任推给了机器。
2. **隐私**：摘要只携带结论，不携带行为轨迹。原始日志里藏着推理不出的
   细节（时间、频率、上下文），摘要把它们留在原地。
3. **可迁移**：纯文本摘要不绑定产生它的系统，换模型、换平台照样可读。
   （Ant International《Text as a universal interface for transferable
   personalisation》, EMNLP 2026 —— 独立印证了本项目的文本优先路线。）

## 人工批准检查清单

审批人看完全文后，逐条核对（任一条不满足即拒绝或打回重写）：

1. **无原文混入**：字段里没有原始日志行、没有 JSON 原文、没有
   `[时间] [INFO]` 式系统行。`bridge.raw_source_hits()` 可做初步提示，
   但它只是噪音过滤器 —— 改写过的原文它发现不了。
2. **摘要忠实**：每条陈述都能在来源里找到依据，没有"看着像"就写上的。
3. **无推断**：禁止想当然。反例 ——
   "送了 235 个小心心" ≠ "喜欢小心心特效"（小心心最便宜，是省钱的支持）；
   "晚上来" ≠ "偏好晚上"（直播只在晚上开，来是必然的）。
   证据只能支持证据本身。
4. **只含模板字段**：三个模板之外没有自由文本字段可供夹带。

## 非目标

- 本 ADR 不改变"桥默认拒绝、全文人工批准"的既有治理；
  它只是把"传什么"从实践写成明文。
- 本 ADR 不要求机器自动判定忠实度（不可靠，不硬上）。
