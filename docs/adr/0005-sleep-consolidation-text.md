# ADR 0005：睡眠巩固走文本版，不走权重版

- 状态：已接受（2026-11-03，用户拍板）
- 背景：港中大 / 浙大 Memo 论文（arXiv:2604.27707）主张"海马体 + 新皮层"
  双系统 —— 保留检索式情景记忆，加一条把情景记忆蒸馏进模型权重的异步巩固通道。

## 决定

Stellamem 的巩固通道走**文本版**：定期把近 N 期 episode 小结蒸馏成抽象规律
（pattern 记忆项），纯文本、可追溯（provenance）、可删除、可撤回。
实现见 `compiler/sleep_consolidation.py`；规律项参与 recall 但权重 ×0.8，
低于原始记录。

## 为什么不走权重版（LoRA / MEMIT / TTT）

1. 人格运行在 DeepSeek API 上，模型权重摸不着；
2. 本地微调需要 GPU 时间 + 数据管线 + expertise，超出 50 元/月云预算红线；
3. 权重写入不可逆 —— "撤回某一条记忆"在权重里是未解难题，与 Stellamem
   "能查能改能撤回"的治理要求直接冲突。

## 后果

- pattern 是派生记忆：每条必须带 provenance（来源 episode 列表），
  `status=pending`，需具名人类批准才生效；撤回保留历史。
- 权重那条路留到以后：本地小模型 + LoRA 成本下来、且"单条可撤回"有解时再议。
- 本 ADR 与"备忘录 vs 真记忆"的讨论：文本版巩固解决的是"从记住这件事到
  学会这件事"的组织问题，不宣称达到权重级泛化；愿景与架构的差距如实记录，
  不用话术填补。
