# v3 原始输出离线复核

本次只评估编号解析契约。输入为 #152 的完整封存结果 JSONL。Python 3.10+ 标准库即可运行，无须 GPU、模型、Node 或网络。v3 正式结论按原契约保留，重放只提供事后诊断。

两个规则对每档 A、R0、R1 的全部原始输出对称使用。沿用 #152 的首尾空白处理。严格规则接受实际送给该臂阅读器的裸编号。候选规则另接受整个输出恰好为一个半角方括号包住的已送达编号。NONE 仍是显式拒答；无材料、未送达编号和其他格式分别统计。正文、多编号及混合 NONE 与编号均不能触发选择。原句复述可能暗示选择，也可能只是提及，汇总另列其中提及的金标、其他已送达编号、未送达编号与多编号的题号，不给分。

工具核对完整的 120 组三臂、360 行、冻结提示摘要、配对材料一致性、六个交叉负例及原三项安全计数。对每行重新推导旧选择、拒答类别和官方正确标记，出现分歧即停止。输入的 SHA-256 写入结果，便于验收员与本机存档核对。新摘要只含计数、题号、哈希与原判定；原始文本留在本机。本工具以 #152 当次记录的核验结果与候选名单为依据。

每档每臂的 strict、bracket 都列出正例答对数、正例错选数、负例误答数、其中交叉负例误答数；后两个数是包含关系。changed_ids 单列正例救回、正例放出错误、交叉负例及普通负例新增误答。forms 区分模型原样给出 NONE 与解析失败。contrast 同时报告对两版提示应用同一规则的差值，以及候选方案相对原试用版严格解析的差值。汇报三档数字即可，无须发出私有 JSONL。
