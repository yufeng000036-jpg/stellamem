# 规模 × 语义 · Windows 本机独立验收

本实验复用 #150 原封不动的投影模块、BGE-M3 编码器和 Jarvis 阅读器。代码与试用版分开，索引位于内存，所有模拟记忆和两个异主体对照只写在临时目录。运行器只连接 127.0.0.1 上已经启动的两个模型服务。表格中的条数是当前用户可见原文数，两个已遗忘原文和两个异主体记录另计。

| 档位 | 基础原文 | F 公式 | G 生活记录 | H 替换实体 / 替换属性 / 旧值挂他名 |
|---|---:|---:|---:|---:|
| T1 | 20 | 0 | 0 | 0 / 0 / 0 |
| T2 | 20 | 320 | 100 | 20 / 20 / 20 |
| T3 | 20 | 1460 | 400 | 40 / 40 / 40 |

语料、原文标识与插入顺序在同档 A/B 间一致，各档保留较小库的全部原文。基础笔记走 Jarvis 写入、批准、遗忘接口，各档复制同一份快照。批量干扰及 persona/viewer 对照采用带原文文件的合成快照，不代表逐条人工审批测试。按 claim ID 排列以固定平分时的初始顺序。G 有 40 个手写生活场景，按人物及地点组合。三个规模同时改变条数和干扰构成，逐题归因可说明掉在哪一层，独立估计各类干扰的因果效应还需要单变量对照。

## 先跑公开样例

解压后在含 benchmark 的目录打开 PowerShell。在本机分别加载已验过的 BGE-M3 和 Qwen3-4B，按照各自服务 /v1/models 的实际值替换模型 ID 和阅读器端口。脚本校验嵌入权重文件完整哈希与两端公开 ID，验收员核对正在提供服务的实际权重。此脚本不负责模型服务的启动和退出。

```powershell
$py = 'E:\Python\python.exe'
$dir = 'benchmark\jarvis_semantic'
$run = "$dir\scale_v2.py"
$models = @('--gguf','E:\kvmem\embed\bge-m3-Q5_K_M.gguf','--embed-model','实际BGE模型ID','--reader-model','实际Qwen3-4B模型ID','--reader-port','实际阅读端口')
& $py $run @models --public-smoke --manifest "$dir\scale_public.json" --out "$env:TEMP\jarvis-scale-public-v2.jsonl"
```

公开样例有 20 条现行、2 条旧版和 3 个公开问题，跑完整三档。文件末行应为 complete，pairs 为 9，passed 为 null。输出始终新建，复跑公开预检请另选文件名。

## 再在本机一次性验收

1. 核对封存原件完整 SHA-256。题目、答案、原件、映射和逐题结果保留在验收员的独立目录。在任何模型作答之前按原顺序转换为公开样例的 notes/questions 结构。id、text、status、gold 保持原义，负例 gold 为 null。题型按 ID 首字母 D/E/N 区分，其他编号可增加 group 字段。封存约定为 22 条原文（20 条现行）、40 题（D20/E8/N12）。v1 的 32 题继续使用 #150 入口作回归，两个题集分别报告。
2. 为可机械替换的现行笔记标记原文中只出现一次的实体片段 entity、属性片段 attribute 及语义不同且与原值相容的 alt_attribute（例如“橱窗展品”与“门票图案”）。旧版笔记标记实体。对没有自然替换位置的字段可省略。三类均须有来源，建议标出所有适用原文。脚本依封存顺序轮转来源，具体别名及分布固定。属性映射留在验收员手上；它是封存后生成的实验输入，独立记录映射件哈希。
3. 离线预览生成清单，核对实体和属性替换是否成立、两条更正记录是否正确、生成记录有没有给负例或正例增加第二个有效答案。预览不调用模型。若金标已变得不唯一，报告数据阻塞，保留原题和原标准。三个语料哈希应与正式结果的 corpus 行一致。
4. 在同一冻结代码和本机服务上执行一次正式评测，指定不存在的新结果文件。成功完成写出 120 对、240 条 question 记录。程序异常或超时留下部分记录，不产生完整成绩；安全事件立即写出 boundary_failure 并退出。指标未过时，完整记录 passed=false，退出码 1。公开样例通过或一次失败后调参均不能替代封存成绩。

```powershell
$private = 'E:\jarvis-sem\private'
$map = "$private\v2-map.json"
& $py "$dir\scale_corpus.py" $map "$private\v2-inventory.jsonl"
& $py $run @models --manifest $map --sealed-original "$private\实际封存原件" --sealed-hash '封存时保存的完整64位小写SHA256' --out "$private\v2-result.jsonl"
```

## 判读和回报

A 保留字面检索，B 使用前八语义候选、等权 RRF 60、同样的 3000 字符及五条证据上限。阅读器提示、过滤和选证机制沿用 #150，temperature=0、seed=7、输出上限 384。每题独立，按 AB/BA 交替。已知 E02 的观测是模型见到正确原文后回 NONE，本实验记录来源类型与实际材料；单个失败的因果仍需另外验证。

每题包含语义前八修订号、正确原文在前八内的名次、融合裁剪前名次、裁剪原因（含 char-cap）、投影名次、前五条、实际送模 ID 顺序、干扰类型、原始模型选择、最终引用 ID 和引用核验。sources 行提供实验标识、claim、revision 的私有映射。program_no_material 表示未调用模型，model_none 表示模型明确拒答，selected 表示选中，另外单列协议异常 invalid_model_selection。负例有真实引用却答非所问单独计数。旧值挂他名保留的是值，泄露检查看被撤销原文的身份及实际投影内容。每次引用都与原文核对，异主体控制在编码及原始投影处检查。

每档汇总包含 D/E/N 分项、配对得失题号与延迟中位数。建索引含资格和原文核验、批量编码，不含准备合成库；逐题端到端含投影、阅读器和 B 的查询编码与排序，包含研究运行器开销。正式通过要求 T2、T3 分别满足正例净增至少 3、B 召回@5 ≥ A、实体净差 ≥ −1 且丢题 ≤ 2、B 负例误答 ≤ A 且 ≤ 2；任一档跨主体、撤销泄露或失效引用均立即判失败。T1 作为参照。

将 metrics、complete 或 boundary_failure 中的计数、题号及原件和映射哈希回报即可。逐题原文、原始模型选择、私有映射和 JSONL 留在本机。本实验不升级 Jarvis；退出后可继续使用原试用版。
