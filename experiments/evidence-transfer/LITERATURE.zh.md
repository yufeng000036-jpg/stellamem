# 相关研究与原创性核查
检索截至北京时间 2026-11-24。优先使用作者论文、评测仓库与正式出版页。下表“指标”均描述作者使用的指标或报告的结果。本研究仅自行运行其中的 LoCoMo 日期切片。成本是按依赖给出的复现工作量；未实际付费测量的工作不报人民币估价。

| 工作及来源 | 问题、方法和开放材料 | 指标与限制 | 对星忆的意义与复现成本 |
|---|---|---|---|
| LongMemEval，ICLR 2025；[论文](https://arxiv.org/abs/2410.10813) · [代码／数据入口](https://github.com/xiaowu0162/LongMemEval) | 500 个长期问答，覆盖跨会话、更新、时间、拒答等；支持 oracle 会话与长干扰历史 | QA 判分与检索指标可分开；2025-09 清理版历史有变化；oracle 与 S/M 不可互换 | 固定数据修订和文件哈希；缓存复核低成本，全量抽取生成昂贵 |
| LongMemEval-V2，2026；[项目](https://xiaowu0162.github.io/longmemeval-v2/) · [代码](https://github.com/xiaowu0162/LongMemEval-V2) | 从多模态网页智能体轨迹学习环境经验，公开数据准备、基线与评估器 | 测可迁移环境知识问答；任务和历史形态区别于私人中文会话 | 可作跨领域验证；轨迹解析、多模态读取和生成开销较高 |
| LoCoMo，ACL 2024；[论文](https://aclanthology.org/2024.acl-long.747/) · [代码和数据](https://github.com/snap-research/locomo) | 长期对话、QA、事件总结，多类问答带对话 ID；生成后经人工整理 | 常见评测含 QA F1；本研究另注册严格日期和引文指标。发布数据只有 10 个顶层对话，按题检验易虚增样本量 | 本轮已跑 CPU；适合追踪原文、跨轮指代、人名与时间。数据许可 CC BY-NC 4.0 |
| Memora，ACL Findings 2026；[论文](https://aclanthology.org/2026.findings-acl.1337/) · [实现与数据](https://github.com/geniesinc/Memora) | 周、月、季度的记忆合并与反复修改，考记忆、推理和推荐 | FAMA 单独惩罚失效记忆。生成的长期叙事并非生产数据，事实变更与授权撤回是不同事件 | 复用过期/当前双标签；加载评测低成本，重跑多模型多时间跨度较高 |
| MemDelta，2026 预印本；[论文](https://arxiv.org/abs/2606.29914) · [逐题输出和评估代码](https://huggingface.co/datasets/memdelta-bench/memdelta-benchmark) | 用 LongMemEval-S 横比原文、记忆架构、模型、提示与写入成本 | 匹配对照后优势会随模型、检索与设定变化；发布的是结果与评估器，基础题来自 LongMemEval | 优先复算缓存，计入写入费用；全量重新生成另计，不把基座差算给记忆 |
| MemGPT／Letta；[论文](https://arxiv.org/abs/2310.08560) · [官方代码](https://github.com/letta-ai/letta) | 在有限窗口中由智能体管理分层记忆，论文含文档阅读与多会话任务 | 侧重有限上下文内的任务表现；当代 Letta 版本与原论文配置应分开锁定 | 作为分层上下文对照；需启动服务、模型并计入额外内存操作与调用 |
| Mem0，2025；[论文](https://arxiv.org/abs/2504.19413) · [源码](https://github.com/mem0ai/mem0) · [评测](https://github.com/mem0ai/memory-benchmarks) | 持续提取、合并、检索，含图增强方案；论文以 LoCoMo 等比较 | 作者报告回答质量、token 和延迟；版本、写入提示、判官与后端均影响结论 | 作为结构化对照；需计入抽取与嵌入，需区分本地版和托管版 |
| A-MEM，2025；[论文](https://arxiv.org/abs/2502.12110) · [实现](https://github.com/agiresearch/A-mem) · [评测](https://github.com/WujiangXu/AgenticMemory) | 动态生成笔记、建立关联、更新旧记忆。作者比较六种基础模型 | 长对话 QA 与不同模型的结果；链接本身不能证明归属或事实当前有效，写入有模型成本 | 借鉴事件关系；先在相同调用预算下与原文检索比较 |
| Selective QA over Conflicting Multi-Source Personal Memory，2026；[论文](https://arxiv.org/abs/2605.30087) | 人工控制多来源冲突和缺证，480 人设、四种种子、34,560 个实例 | 可比较回答／拒答与冲突消解；模板族与自然话语差异较大。本次核实论文，未固定代码版本 | 拒答策略及其公平测试已有先例；合成测试便宜，完整生成另计 |
| Agent Zero Memory，2026；[论文](https://arxiv.org/abs/2608.29606) | 事件时间线、关联图、引用锁定并行；记录来源、时间与证据指针 | 作者报告 LongMemEval/LoCoMo；只许引用打开过的记录仍不能保证蕴含。未独立复跑，未锁定可复现全栈 | 引用来源、时间与多层结构已有先例；全量生成与图构建成本较高 |
| MemCut，2026-10；[论文](https://arxiv.org/abs/2610.21405) | 456 个合成长对话秘密及证据轨迹，区分从系统检索恢复与从残余证据恢复 | 剩余与原生可恢复率；一条输出未泄漏不证明已从所有衍生存储删除。本轮未执行其生成实验 | 把删除后的检索、缓存与派生数据分别测试；先用合成探针 |
| AfterDeleteBench，2026-10；[论文](https://arxiv.org/abs/2610.31366) | 源删除后分别测信息重构、写回与新会话召回 | 作者比较不同删除／过滤策略；特定探针下 0 恢复不等于一般不可恢复。未核验可运行代码版本 | 复用三个阶段；磁盘检查与行为恢复开销分别记录 |
| LEDGER，2026-11；[论文及复现实验描述](https://arxiv.org/html/2611.20927v1) | 模型提议事实，规则处理有效期、来源优先与删除，另有原文回退；和无记忆、全历史、原文检索、Mem0 同读者比较 | 合成编码任务以外，作者在 LongMemEval 的 210 题上报告最强系统差异处于区间内。未独立复跑；不能直接移植其得分 | 与 H1 最接近的已知先例；先核对其同预算原文基线及事件版本设计，全量重生成另计 |

**已能稳定完成的局部工作**包括固定数据指纹、保存原发言 ID、对明确民事日期作确定性运算、在给定的判分定义下精确复算成对转移。**已有方法但稳定性不足**之处包括用词面或引文 ID 判断支持、跨会话汇总、更新与删除后阻断所有衍生推断、低预算下保持回答覆盖率。**仍值得验证的研究空间**是同模型和同预算下，按可验证的事件角色、时间和授权信息校准作答，在未知中文自然会话中与强原文 RAG 同时比较新增正确、错答和过拒。方法组件均有前例；本研究未建立优先权或全球最佳的结论。
