Jarvis V0.1 中文试用指南

第一次使用（先不用模型）
1. 在 Windows 11 把整个 ZIP 解压到自己的普通文件夹，例如“下载\Jarvis 试用”。请先解压，不要在压缩包预览窗口中启动。
2. 双击 Check.cmd。它显示本机系统与依赖版本，在临时目录运行离线验收，可使用普通用户权限。看到“通过”后再试用；看到错误请保留窗口提示。测试使用合成文件和临时数据库。
3. 双击 Start.cmd。程序需要 Python 3.10 以上（推荐 3.12，包含标准库 SQLite）和 Node.js 22 以上。包内自带项目与 Stellamem 代码；这两个运行时由你电脑提供。没有 pip、npm、管理员安装或自动升级步骤。缺少依赖时启动器会指明是哪一项。
4. 窗口会显示实际数据位置。新试用版默认使用 %LOCALAPPDATA%\Jarvis-Trial-V01。不要把生产项目、系统目录、同步盘或其他人的目录用作实验目录。
5. 输入“帮我记个待办，整理三张作品照片”。看清内容后输入当次确认码；直接回车即取消。输入“我的待办有哪些”查看，再用“完成 1”标记第一项。输入“退出”后重开检查编号和状态。

试一条记忆
输入“记下 星桥会议在周六下午”，确认。输入“待审核”，复制修订号，输入“批准 修订号”。窗口会再次显示原话。批准后输入“查记忆 星桥”，可看到原文、引用编号及来源位置。没有模型也能查询。只有“问记忆 问题”会把已经核验的候选交给已配置的本地模型。

只读文件
把愿意授权的 UTF-8 文本复制进窗口所示实验目录的 documents 文件夹。只复制试用资料；支持 .txt/.md/.json/.csv，单个文件最多 64 KiB。输入“文件”看列表，再试“读 中文 文件名.txt”。控制台解释所在目录、文件类型并展示原文。资料中的命令只是内容。先核对文件身份和用途，后续整理方案须另行讨论；本版没有文件移动、改名、删除或覆盖命令。

备份、恢复、停止
输入“备份”并确认，记录输出的完整备份路径。备份包含待办、操作日志、停用状态和记忆资料（含历史原文）。授权文档和模型配置需另存。关闭程序，在解压目录的终端运行 Start.cmd --home "备份目录完整路径"；在 PowerShell 中使用 .\Start.cmd。这样直接使用独立备份副本，不覆盖损坏的原目录。“停止”会阻断后续命令；“恢复”需要再次确认。
“遗忘 记忆号”会使有效记录退出召回。原始笔记、事务历史和以前创建的备份仍可能保留内容，恢复早期备份可能重新带回它。请勿将此功能当作彻底擦除敏感信息。

你的 Windows 11 最后验收
□ 用普通用户运行 Check.cmd，记录显示的系统和版本。验收脚本不会更改生产配置。
□ 手动取消、批准各一次；关窗、重新打开；下次正常重启电脑后再查同一待办和记忆编号。
□ 从备份副本启动；检查记忆、待办和停止开关。先保留原目录。
□ 在 LM Studio 中加载现有本机模型并启动本地服务器；确认使用本地推理后双击 ModelCheck.cmd，输入模型 ID 和端口。这会使用合成材料检查中文多轮、逐题召回、选证、答案、拒答和引用。只有你同意后才运行。报告保存在屏幕提示的新建 JSON 中；不上传。
□ 日常聊天需要在数据目录放 model.json，例如 {"port":1234,"model":"实际加载的模型ID"} 。退出模型服务后再试一次待办和读文件。
□ 可选：输入“说话”按回车听写一句话；输入“朗读 你好”试听。缺少中文语音组件时继续用文字。
□ scores.tsv 是 50 道固定题及标准原文，请逐项复核并标出歧义。不以开发者自拟答案代替用户的独立人工验收。
