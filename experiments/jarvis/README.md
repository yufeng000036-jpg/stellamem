# Jarvis 私人助理 V0.1

一个单人使用的中文本地控制台。待办、查原文和读文件均可离线运行。实验代码放在独立目录，只复用同一提交的 Stellamem 代码。无需运行 Stellamem 安装程序，无需配置生产目录。

本轮普通用户教程见 FIRST-STEPS.txt，冻结 50 题逐题比较见 scores.tsv。解压试用包顶层可以直接双击 Check.cmd、Start.cmd 或 ModelCheck.cmd。

## Windows 启动

1. 完整解压下载包，保留目录结构。建议使用已安装的 Python 3.12 和 Node.js 22 或更新版。可用 `py -3 --version` 和 `node --version` 检查。没有 pip/npm 安装步骤。
2. 双击 `experiments\jarvis\Start.cmd`。首次启动在当前 Windows 用户的 `%LOCALAPPDATA%\Jarvis-Trial-V01` 创建独立目录。控制台打印实际路径。输入“帮助”查看命令。
3. 先输入“帮我记个待办，明天整理三张作品照片”。核对事项，输入本次显示的确认码，再输入“我的待办有哪些”。关掉窗口再打开，仍应看到同一个编号。
4. 把允许读取的 UTF-8 文本复制到上面实验目录的 `documents` 下。输入“读 会议.md”。相对路径允许子目录，文件上限 64 KiB。内容只展示在终端。

## 带来源的记忆演示

输入“记下 星桥会议定在周五上午”，确认后输入“待审核”。输入“批准 修订号”，控制台会再次展示待批准的原话。批准后保存返回的回滚号。关掉程序重新启动，输入“查记忆 星桥会议”。输出含记忆编号及原文位置，相对路径以实验目录下的 memory 为起点。每次查询重新核对原文字节散列、内容、说话人、有效状态与 Stellamem 的投影结果。命中示例和实际运行输出见 linux-run.txt。

更正有两种方式。刚批准且没有后续冲突时，“撤销批准 回滚号”把它退回待审。已失效的事实可以“遗忘 记忆号”，人工确认后停止召回，然后录入并审核正确原话。两步分别记录，期间查询可能没有匹配。遗忘采用 Stellamem 的 tombstone 模式。原始笔记、事务前镜像和已有备份仍含历史内容。V0.1 无彻底擦除功能。

## 本地模型与语音

确认 LM Studio 已加载本地模型且服务**确实本地推理**后，在实验目录新建 UTF-8 的 model.json。把 model 改为你已加载模型的实际标识，port 改为其本地服务端口。

```json
{"port":1234,"model":"your-loaded-local-model"}
```

“聊 你好”使用内存中的最近四轮对话。“问记忆 星桥会议改到哪天”只将该问题及已核验的候选交给模型选择，然后程序回显原文及编号。无匹配、模型编造编号或不按格式回复时拒答。有效编号仍可能选错。对话契约里另有一条长期规则：记忆是线索，不是现况证据——涉及现状时先核对现状，不把记忆里的说法直接当成当前事实。模型服务离线时可以继续“查记忆”。先访问 127.0.0.1 的 /v1/models 核对模型 ID，再调用 /v1/chat/completions，不读系统代理、云端密钥或 DSH 配置，不跟随重定向。任意自建转发代理的后端不能由 Jarvis 判定；只配置自己确认是本地推理的端口。本轮没有调用云服务。

可选语音依赖 Windows PowerShell 5.1、系统自带 System.Speech、已安装的中文桌面识别器/语音和用户现有麦克风权限。“说话”按回车启动单句识别，听写结果只显示为草稿。“朗读 文本”调用本地合成。系统策略阻止脚本或缺少组件时仍然可以打字操作。尚未验证用户的真实音频设备。

## 权限、日志与停止

| 能力 | 允许的范围 |
|---|---|
| 文件 | 只读 documents 内普通 UTF-8 的 txt/md/csv/json；不能浏览任意盘符 |
| 待办 | 实验 SQLite；新增、完成与重开逐次确认 |
| 记忆 | 独立 Stellamem 根，固定 user/global；记下、批准、撤销、遗忘逐次确认 |
| 模型 | 默认关闭；配置后普通对话发送输入和短会话历史，“问记忆”另发送本次候选 |
| 语音 | 手动单句触发；无后台监听或自动执行听写 |
| 备份 | 确认后在实验目录旁新建副本；排除授权文档和模型配置 |
| 外部动作 | 无账户、支付、Shell 工具、邮件、私信、评论或抖音接口；模型输出不会被执行 |

输入“停止”会清空当前窗口聊天上下文并持久阻断后续任务。输入“恢复”需要确认。“退出”或 Ctrl+C 结束窗口；对正在进行的请求，可以直接关闭进程。命令在实例锁内串行执行。建议单窗口使用。输入“日志”查看时间、动作和结果；Jarvis 的操作日志不记正文，Stellamem 的审核记录和事务另存，并含记忆内容。实验目录及备份为普通本地文件，同一系统账号下有文件权限的其他程序可读取；请使用独占且不被其他进程改写的目录，不放入同步盘。

## 备份及回滚

输入“备份”，确认后记下返回路径。关闭当前控制台，在项目目录运行下列命令，可直接以备份作为独立工作副本验证恢复，无需覆盖原目录。模型配置和授权文档由操作者按需重新提供。

```powershell
py -3 experiments\jarvis\jarvis.py --home "C:\本地路径\jarvis-backup-实际编号"
```

停止使用时退出即可。程序没有安装后台服务、开机启动项或宿主插件。代码回退可切回先前分支。独立副本中的任务和记忆只在指定副本内变化。

## 复现与待验收项

在解压目录运行 `py -3 -X utf8 experiments\jarvis\acceptance.py`。测试自动创建临时目录、合成原文及 localhost 协议替身，不读取个人文件。测试程序代为确认或拒绝；实际 UI 使用随机确认码。详细审查和限制见 REPORT.md。

真实 Windows 验收需用新目录完成以下项目：确认与取消随机码各一次、重启查回原文、暂停后恢复、用独立备份启动、带空格的中文路径、NTFS junction 和备用数据流拒读、LM Studio 实际加载模型后多轮聊天和“问记忆”、断开模型后继续工作、麦克风听写与扬声器播报。OpenClaw 的测试应另建隔离宿主，覆盖撤销传播、会话重写、压缩及宿主重启；生产 DSH 或用户历史不能作为默认测试输入。
